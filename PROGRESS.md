## How this file is made

- Each row comes from a task heading (like `## T1. ...`) and its `- Due:`, `- Status:`, `- From:` and `- Pull request:` lines.
- A GitHub Action rebuilds it on main every hour and after every merge, reading main and every officer branch ("Read from" shows which). A branch only counts for its own task, and "verified" only counts from main.
- "Days left" is counted from the day the file was generated, in Manila time.
