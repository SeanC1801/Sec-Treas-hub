# SecTreas Hub

A web app for the AUF-ACM Student Chapter's Treasurer and Secretary. Fill in a form and the hub makes the official document (budget requests, liquidation reports, minutes, certificates) in the chapter's format, ready to print, and tracks its approval status.

Officers working on the hub (Nico and Ian): start at [SecTreas - Harness/START-HERE.md](SecTreas%20-%20Harness/START-HERE.md).

## Setup

```
git clone https://github.com/SeanC1801/Sec-Treas-hub.git
cd Sec-Treas-hub
npm install
npm run dev
```

Then open http://localhost:5173. All data in the draft is sample data, saved in your browser only.
